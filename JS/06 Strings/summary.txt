* Strings in JavaScript are the sequence of characters enclosed in single quote, double quote or backticks.
* String is internally a JavaScript Object with built-in properties and methods.
* One of the properties of String is the length property which gives the number of characters in the string.
* Each character in string is assigned a position number called the index number which starts from 0.
* We can access a specific character by it's position number just in the way we access Object properties.

* Template literal is a way of writing strings with embedded expressions using placeholders in string instead of concatenating multiple strings.
* Template literals are declared by using backticks.
* String interpolation is the major characteristic of Template literals.
* String interpolation means embedding variables and expressions inside the string using ${}.
* We can nest another Template literal in expression placeholders ${}.
* tagged Template is a function that accepts a Template literal as argument without parenthesis during function call.
* tagged Template function first argument is an array of the strings and second argument is the array of expressions used in Template literal.
* The length of string array is always one greater than that of the expression array.

* Escape sequence allow us to print special characters inside strings.
* Escape sequence character starts with back-slash along with the character to be printed.
* Although, the escape character consist of two characters, but in strings it is treated as a single character.

* In JavaScript, Strings are immutable i.e We cannot change or modify the original string.
* There are some methods related to strings in JavaScript.

- toUpperCase(): Converts all characters in a string to uppercase letters.
- toLowerCase(): Converts all characters in a string to lowercase letters.
- trim(): Remove the starting and ending spaces from the string.
- slice(): Returns a substring of a string by specifying starting and ending index where the ending index in exclusive.
- concat(): Concatenate one string with another string. Alternatively, we can use the + operator.
- replace(): Replace the first occurrence of substring with another substring.
- replaceAll(): Replace all occurrences of a substring with another substring.
- charAt(): Returns the character in the specified index of a string. Alternatively, we can use square bracket method.
