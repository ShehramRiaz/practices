* Strings in JavaScript are the sequence of characters enclosed in single quote, double quote or backticks.
* String is actually a JavaScript Object with built-in properties and methods.
* One of the properties of String is the length property which gives the number of characters in the string.
* Each character in string is assigned a position number called the index number which starts from 0.
* We can access a specific character by it's position number just in the way we access Object properties.

* Template literal is a way of writing strings with embedded expressions using placeholders in string instead of concatenating multiple strings.
* Template literals are declared by using backticks.

* Escape sequence allow us to print special characters inside strings.
* Escape sequence character starts with back-slash along with the character to be printed.
* Although, the escape character consist of two characters, but in strings it is treated as a single character.
