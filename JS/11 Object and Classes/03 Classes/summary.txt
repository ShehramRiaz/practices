* A class is a blueprint for creating objects.
* The class name is written in PascalCase by convention.
* constructor method is used to initialize the Object and is called automatically when an object of that class is created.
* Unlike Old Constructor Functions, methods are written directly inside the class declarations.
* The methods defined in class are shared among all Objects.

* The extends keyword is used to inherit properties and methods from another class.
* If inherited class has it's own constructor defined, super() must be called.
* super is used to call the parent class constructor.
* If inherited class has no constructor, Javascript implicitly create an empty constructor and calls super();
* We can also call the parent class methods by using super.parentMethod();

* We can associate methods to the class itself by using static methods.
* static keyword is used to make a function static.
* We can only call static method from Class
* static method cannot be called from instances of the class.

* Getters and Setters allow us to use the methods as if they were properties.
* Getter can be declared by preceding method declaration by get keyword.
* Setter can be declared by preceding method declaration by set keyword.
* Getter do not have any parameters, it only return values.
* Setter must have exactly one parameter.
* Setter do not accept more than one arguments.
* One pair of Getter-Setter method can have same name.
* They are used just like other properties of object without parenthesis.
