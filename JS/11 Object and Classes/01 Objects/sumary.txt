* An object is a collection of related data and functionality stored as key-value pairs and separated by comma.
* It can store any type of data.

* We can access individual property by using either dot or bracket notation.
* Dot property accessor is used when we know the name of the property or the name of the property is a valid JavaScript Identifier.
* Bracket property accessor is used when the property name is stored in a variable or the property is not a valid JavaScript Identifier.

* Objects are dynamic, we can add or update properties dynamically in Objects.
* Object properties can be deleted using the delete keyword.

* In addition to properties, Objects can also store functions which in context of Objects are called methods.
* So, method is just a function that belongs to an object.
* Methods in objects are used to perform some actions on the properties of object.

* Methods can access object properties by using the this keyword.
* this keyword in a method refers to the object which called that method.
* Arrow functions should be avoided as object methods because it inherit this from parent function which is called by an object.

* Unlike primitive datatypes that are store by value, Objects are stored by reference.
* When we assign an object to a variable, it's reference is stored in the variable not the object itself.
* So changes made in one variable will be reflected in the other because there is only one object stored in memory.

* When comparing two objects having same properties return false because we are actually comparing the object references, not the Objects.

* There are two types of Copies:
- Shallow Copy
* The outer object is copied but the inner objects are still shared.
* Changes in the inner objects of copy will be reflected in the original.
* The spread Operator performs a shallow copy.

- Deep Copy
* A deep copy creates completely independent copies, including all nested objects.
* structuredClone() function can be used to perform a deep copy of an object.
