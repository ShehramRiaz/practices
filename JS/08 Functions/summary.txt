* Functions are reusable block of code that perform a specific task.
* Functions perform it's task when it is called\invoked.
* We can call a function as many times as we want.
* It can also take parameters to accept input from outside.
* The parameter variables are defined inside the parenthesis of the function definition.
* These parameters are initialized when the function is called with arguments passed in parenthesis.
* The scope of the parameters in functions are block scoped.
* Functions can also return values to the place where the function was called using return keyword.
* The code written after return keyword in a function never runs.
