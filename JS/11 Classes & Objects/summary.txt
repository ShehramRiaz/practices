* Objects are Javascript entities which has some states (properties) and behaviour (methods).
* this keyword in Javascript refers to the object in which it is used.
* Prototypes are objects from which another objects inherit properties and methods.
* We can get and set Prototypes of an object through getPrototypeOf() and setPrototypeOf() methods.
* When a method is called, Javascript first checks the method inside the object. If method is found in Object it execute that method. Otherwise, it checks for the method in the prototype and then in another prototype and so on.

* We can create Objects in two ways:
- Object Literals: The Classical Method by writing properties and methods manually inside curly braces.
- Classes are the templates or blueprints for creating Objects efficiently.

* new keyword can be used to instantiate Object from Classes.

* Constructor is a special method defined in class which is called automatically by the new keyword when an object of that class is instantiated.

* Constructor method is created like any other method but the name of the function is always the keyword constructor.

* It is used to initialize the object.

* It can accept arguments to initialize the object.

* Arguments are passed to constructor during object creation.

* Programming in this way is called Object Oriented Programming (OOP).
* Inheritance is the feature of OOPS that allow us to create classes that inherits properties and methods from another existing classes without rewriting the same code again.
* It is achieved by using extends keyword.
* The class that inherits properties is called Child or Derived Class whereas the class from which the child class is inherited is called Parent or Base Class.
* If the derived class has it's own constructor then it must first call the parent constructor by using super() before using this keyword. Otherwise, Error will be thrown.
* If Parent and Child Class have same methods, the child method is called. This is called method overriding.

* In Javascript, Objects are stored by reference not stored by value.
* When an existing object is assigned to another variable, it's reference is copied to that variable not the object itself.
* Any change to one variable will affect the other variable having the same object reference stored.
* Similarly Objects are passed by reference in functions as argument and any modification by the function on the object reference is reflected in the original Object.
