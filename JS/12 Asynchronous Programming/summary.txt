* Based on the execution sequence, there are two types of Programming.
- Synchronous Programming: The style of programming in which the statements are executed one after another.

- Asynchronous Programming: The style of programming in which some statements execute in parallel with another statements.

* In programming, some statements or block of code may take some time to execute. So they are executed in parallel with other statements.

* Sometimes we have to wait for the result of the Asynchronous Operations and then use that result to perform other Operations.

* I means the result handler must run after the result is generated by the Asynchronous code.

* Javascript provides three ways to handle the result of an Asynchronous code.

- Callbacks: 
* The Callback is a function passed to other function. So When the Asynchronous result is calculated, the Callback runs.
* Callback has a problem called Callback Hell.
* The nested Callbacks form a pyramid like structure in the code which is hard to read and understand. That pyramid problem is called Callback Hell or Sometimes called Pyramid of Doom.

- Promises:
* Promise in Javascript is slightly more good and readable way of handling result of Asynchronous Operations.
* The promise can have one of three states pending, fulfilled, rejected.
* We can fulfill promise by using resolve callback function provided by the promise Class.
* We can reject promise by using reject callback function provided by the promise Class.
* If promise is neither rejected nor fulfilled, the promise state would be pending.
* Javascript provides two functions to handle the result of promise.
* then() method is called when the promise is fulfilled and it receives the resolved value as it's argument.
* catch() method is called when the promise is rejected and it receives the rejected value as it's argument.
* We can chain the then functions one after another.

- async await:
* async await are keywords which significantly simplifies the way we handle the result of Asynchronous Operations.
* async keyword enable a function to use the keyword await and automatically return a promise.
* await keyword is used inside the async functions which stops the execution of the code after it.
* The only drawback of using async await is that it requires a separate async function to use the keyword await.
* IIFE Immediately Invoked Function Expressions solves this problem by allowing us to create anonymous functions that is executed at the place it was created.
