* In any programming languages, operators can be used to perform an action on it's values called the operands.

* Arithmetic operators: +, -, *, /, %, **
* The % operator gives the reminder of two values.
* The  ** operator is the exponentiation operator.

* Assignment Operators: =, +=, -=, *=, /=, %=, **=, ++, --
* The ++ and -- are unary operators which can be used as either post increment/decrement or pre increment/decrement.
* Post increment/decrement first return the value then increase/decreases value by 1.
* Pre increment/decrement first increase/decreases value by 1 then return the value.

* Comparison Operators: ==, !=, ===, !==, <, >, <=, >=
* They return a boolean value.

* Logical Operators: &&, ||, !
* The logical AND (&&) operator requires both of it's operands to be true to return true.
* The logical OR (||) operator requires at least one of it's operand to be true to return true.
* The logical NOT(!) operand negates (toggle) the boolean value.
