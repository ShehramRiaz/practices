* if-else statements can be used to execute a block of code when the given condition is matched.
* We can chain as many else-if after if as we want and then place an optional else statement which executes only when no condition is met.

* Ternary operator ?: is the only operator in Javascript with three operands.
* Ternary Operator is a compact form of if-else statement.
* It executes only one statement based on the condition.
* It is usually used for small statements.

* switch statement can be used to check an expression for different possible values.
* break keyword should be used in each case to pass the execution control to the line just after the switch block.
* default keyword is executed when no case is matched.
* break statement is optional in default statement.
